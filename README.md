# Aplicación Web: Galleta de la Fortuna (Fortune Cookie)

Este repositorio contiene una aplicación web interactiva desarrollada desde cero como parte de las prácticas del Bootcamp de Desarrollo Web Full Stack. El proyecto se enfoca en el manejo de estados y componentes dinámicos en el navegador.

## Descripción del Proyecto
La aplicación genera de manera aleatoria frases de motivación y fortuna junto con fondos de pantalla dinámicos cada vez que el usuario interactúa con el botón. El objetivo principal fue aplicar la lógica de programación en el entorno del cliente para crear una experiencia de usuario fluida y visualmente atractiva.

## Estructura del Proyecto y Tecnologías
* **React**: Biblioteca principal utilizada para la creación de componentes reutilizables y la gestión del estado de la aplicación.
* **JavaScript (ES6)**: Lógica para la selección aleatoria de datos (frases y rutas de imágenes) mediante arreglos y objetos.
* **HTML5 / CSS3**: Estructuración y diseño adaptativo (*responsive*) para asegurar que la aplicación se vea bien en dispositivos móviles y computadoras.
* **Vite**: Entorno de desarrollo rápido utilizado para compilar y organizar el proyecto de manera eficiente.

## Funcionalidades Clave del Código
1. **Gestión de Estados (`useState`)**: Control del cambio de frases y fondos de pantalla de forma simultánea al hacer clic en el botón.
2. **Lógica de Aleatoriedad**: Implementación de funciones matemáticas en JavaScript para obtener índices aleatorios de un archivo de datos local.
3. **Modularidad**: Organización limpia del código dividiendo la interfaz en componentes independientes para facilitar su lectura y mantenimiento.
